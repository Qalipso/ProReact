# Day 2 — state design

Тема дня: local, lifted, derived, server и URL state. Практика продолжает Day 1
на том же issue triage board.

## Материалы

- [`lecture.md`](lecture.md) — лекция, разбор решений и устный interview checker.
- [`state-inventory.md`](state-inventory.md) — одностраничная инвентаризация состояния.
- [`evidence.md`](evidence.md) — проверки кода и наблюдаемого поведения.
- [`../example-walkthrough.md`](../example-walkthrough.md) — маршрут по единому
  примеру Day 1 + Day 2.

## Практика на 3 часа

1. **45 минут — классификация.** Прочитать разделы 1–4 лекции и для каждого
   значения назвать владельца, lifetime и source of truth.
2. **75 минут — код.** Проследить путь фильтра, выбора, загрузки issues и
   редактирования по файлам из раздела «Карта кода».
3. **35 минут — поломать и исправить.** Временно сохранить `selectedIssue`
   целиком или `visibleIssues` в state и письменно описать, какие два значения
   придётся синхронизировать. Затем вернуть минимальную модель.
4. **25 минут — без AI.** Закрыть материалы и вслух ответить на пять вопросов
   в конце лекции. Каждый ответ — 30–60 секунд и один пример из triage board.
