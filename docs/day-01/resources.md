# Day 1 resources

Primary documentation is the source of truth. Videos reinforce the model; they
do not replace current React documentation.

## Required reading

1. [Keeping Components Pure](https://react.dev/learn/keeping-components-pure)
2. [Render and Commit](https://react.dev/learn/render-and-commit)
3. [State as a Snapshot](https://react.dev/learn/state-as-a-snapshot)
4. [Queueing a Series of State Updates](https://react.dev/learn/queueing-a-series-of-state-updates)
5. [Passing Props to a Component](https://react.dev/learn/passing-props-to-a-component)
6. [Passing Data Deeply with Context](https://react.dev/learn/passing-data-deeply-with-context)
7. [Rendering Lists](https://react.dev/learn/rendering-lists)
8. [Preserving and Resetting State](https://react.dev/learn/preserving-and-resetting-state)
9. [`<StrictMode>` reference](https://react.dev/reference/react/StrictMode)

## Videos

### Watch during Day 1

1. [What Is React And Why You Need To Know It — Web Dev Simplified](https://www.youtube.com/watch?v=1wZoGFF_oi4)
   — components, state, and re-rendering.
2. [Stale Closures in JavaScript and React — Devtools Tech](https://www.youtube.com/watch?v=TQtGQ5lOTX0)
   — concrete closure failures, including React hooks.
3. [Getting Closure on React Hooks — Shawn Wang](https://www.youtube.com/watch?v=KJP1E-Y-xyo)
   — a tiny hooks model explaining closures and stable hook order.

### Optional deep dive

4. [A Cartoon Intro to Fiber — Lin Clark, React Conf](https://www.youtube.com/watch?v=ZCuYPiUIONs)
   — an older but useful visual explanation of scheduled render work. Treat
   current React docs as authoritative for APIs.

## Reading strategy

For each resource, write only three notes: one statement that sharpened your
model, one concrete failure sequence, and one question you can answer verbally.
Read the relevant primary page, reproduce the behavior in code, then use a
video to reinforce the concept that was difficult.
